About Azure RBAC Catalog

A free, open educational resource for Azure security professionals

Our Mission

Azure RBAC Catalog is a completely free, educational tool designed to help Azure administrators, security professionals, and developers understand and work with Azure's Role-Based Access Control (RBAC) system.

We believe that understanding permissions and roles should be accessible to everyone working with Azure, whether you're studying for a certification, designing a security architecture, or troubleshooting access issues.

What We Offer

📋 Complete Role Catalog

Browse all {{ total_roles }}+ Azure built-in roles with full permission details and JSON definitions.

🔍 Operations Browser

Explore {{ total_operations }}+ Azure resource provider operations with detailed descriptions and see which roles grant each permission.

📊 Change Tracking

Monitor when Microsoft adds, modifies, or deprecates built-in roles.

🤖 Role Recommender

Find the least-privilege role for your specific permission requirements using AI-powered recommendations across 7 different matching modes.

⚖️ Role Comparer

Compare any two Azure built-in roles side by side. See shared, unique, and differing permissions at a glance to choose the right role.

📈 Analytics Dashboard

Explore trends and statistics across Azure RBAC — role growth over time, permission distributions, top resource providers, and more.

📡 RSS Feeds

Subscribe to Atom or RSS feeds to get notified when roles are added, updated, or deprecated.

🔌 MCP Server

Connect AI assistants like GitHub Copilot, Claude, or Cursor to query Azure RBAC data directly via Model Context Protocol.

Frequently Asked Questions

Is this tool free?

Yes, completely free. There are no paid tiers, subscriptions, or hidden costs. This is an educational resource for the Azure community.

Where does the data come from?

All role and operation data is sourced directly from the Azure Management API. We scan daily to keep the catalog up-to-date with Microsoft's latest changes.

How accurate is the data?

We pull data directly from Azure's APIs, so it reflects the current state of Azure's built-in roles. However, always verify against official Microsoft documentation for production decisions.

How do I use the MCP server with my AI assistant?

The MCP (Model Context Protocol) server allows AI assistants like GitHub Copilot, Claude, and Cursor to query Azure RBAC data directly.

Setup for VS Code / GitHub Copilot:

1 Open any folder in VS Code — this becomes your "workspace"
2 Create this file: .vscode/mcp.json
3 Paste this configuration and save: 
{
  "servers": {
    "azure-rbac-catalog": {
      "type": "http",
      "url": "https://rbac-catalog.dev/mcp/"
    }
  }
}

💡 Tip: The MCP server will be available whenever you open that folder (or any subfolder) in VS Code. To use it everywhere, add the config to a folder you always have open, or configure it globally in VS Code settings under github.copilot.chat.mcp.servers.

Example questions you can ask:

  • •"What permissions does the Storage Blob Data Contributor role have?"
  • •"Compare Storage Blob Data Contributor and Storage Blob Data Owner"
  • •"What operations correspond to Microsoft.Storage/*/read?"
  • •"Find the least-privilege role for reading Key Vault secrets"

See the MCP documentation for more details.
